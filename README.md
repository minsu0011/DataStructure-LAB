# C 자료구조 실습

자료구조 수업에서 트리, 힙, 그래프와 정렬을 C로 직접 구현했습니다. 라이브러리 호출보다 노드 연결, 연산 과정, 메모리 할당·해제를 이해하는 데 초점을 맞췄습니다.

## 사용 기술

C 표준 라이브러리와 파일 입출력을 사용합니다. 실습별로 독립된 `main`이 있으며 입출력 경로를 인자로 받는 과제가 포함돼 있습니다.

## 과제 진행 순서

| 폴더 | 구현 | 읽어볼 부분 |
|---|---|---|
| [lab05](lab05) | Binary Search Tree | 삽입·탐색·삭제와 노드 연결 |

| [lab09](lab09) | 최단 경로 | 그래프와 우선순위 힙 결합 |
| [lab10](lab10) | Quick sort | partition과 재귀 구간 |
| [lab11](lab11) | Disjoint set 기반 미로 | find/union으로 연결 판정 |

## 구현에서 연결한 개념

BST의 탐색 규칙만으로 트리 높이가 보장되지는 않습니다. 이어지는 AVL 실습에서는 회전으로 균형을 유지합니다. 삽입 위치를 찾는 것과 삽입 뒤 구조를 복원하는 일을 나눠 볼 수 있습니다.

힙은 독립 실습에서 끝나지 않습니다. 최단 경로 과제에서는 앞서 만든 힙을 최소값 우선 처리에 맞게 바꿔 그래프에 연결했습니다. 위상 정렬의 큐와 미로의 disjoint set도 필요한 연산에 맞춰 자료구조를 선택한 예입니다.

## 실행

```bash
gcc lab05/BST.c -o bst
```

입력 형식과 인자는 각 파일의 `main`에서 확인합니다. 다른 실습의 `main`을 함께 링크하지 않습니다. 빈 구조, 중복 키, 메모리 해제 같은 경계를 직접 살펴보며 읽는 실습 코드입니다.
